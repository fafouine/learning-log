# 📚 Learning Log Wiki

Welcome to the wiki — the front door to everything in this learning log. If the repository is a filing cabinet, this page is the index card that tells you where everything lives and how to use it.

## 🗺️ How this repository is organized

| Section | What lives there | Where |
|---|---|---|
| **Logs** | Dated, journal-style entries: what I did and learned each session | [`LOGS/`](../LOGS) |
| **Concepts** | Focused, reusable notes that each explain a single idea | [`concepts/`](../concepts) |
| **Tags** | Auto-generated index cross-referencing logs and concepts | [`tags/`](../tags) |
| **Glossary** | Plain-language definitions of the terms I'm learning | [Glossary](Glossary.md) |

## 🚀 Start here

- **New here?** Read [Getting Started](Getting-Started.md) to see how logs, concepts, and tags fit together.
- **Looking for a term?** Check the [Glossary](Glossary.md).
- **Exploring a topic?** Browse the [`tags/`](../tags) folder for the generated tag index (e.g. `#python`, `#Web_Security`).

## ✍️ Adding to the wiki

The wiki is just Markdown in the `wiki/` folder, so you can edit it like any other note:

- Add a new definition to the [Glossary](Glossary.md) whenever you meet an unfamiliar term.
- Add or update a page here whenever you want a durable, high-level overview of a topic.
- Link generously — connect wiki pages to the concept pages and logs they summarize.
